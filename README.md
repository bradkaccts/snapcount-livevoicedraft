# Draft Whisperer

I want to create a live fantasy sports draft simulator/tracker platform. Let's specifically plan to build a fantasy football live draft simulator. Key features will need to include speech to text conversion so a human can speak into a microphone and the person's selection is captured in the system and streamed back to the UI screen, Based on the results of the selection, I wanted to use an AI agent to search the internet and find highlight videos of the player, we need to be able to programmatically connect to a specific leagues data (yahoo, espn, etc).
